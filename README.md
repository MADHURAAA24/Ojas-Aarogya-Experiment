# Ojas Aarogya Mandir 🌿
### MERN Stack Appointment Booking System

A full-stack web application for an Ayurvedic and Panchakarma clinic, designed to simplify patient appointment booking and manage appointment records online.

### Tech Stack
- **Frontend:** React.js, Vite, Axios
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas, Mongoose
- **Deployment:** Vercel (Frontend), Render (Backend)
- **Version Control:** Git & GitHub

### Key Features
- Patient appointment registration
- Treatment, date, and time selection
- REST API integration
- Cloud database storage
- Live cloud deployment

### Application Workflow
`React → Axios → Express.js → Mongoose → MongoDB Atlas`
